# Future Development

This directory is the creative sandbox for works set in *The Policy* universe. Ideas start here. When an idea gets promoted to "we're writing this," its canon elements get added to the main lore files.

## Contents

| File | Purpose |
|------|---------|
| [sequel-ideas.md](sequel-ideas.md) | Novel-length sequel concepts |
| [short-stories.md](short-stories.md) | Short story and novella ideas |
| [unexplored.md](unexplored.md) | Open threads, unanswered questions, dangling hooks |

## Process

1. Capture raw ideas in the appropriate file
2. Develop promising ideas with character notes, plot sketches, thematic questions
3. When ready to write, promote canon elements to `lore/*.md` files
4. Write the new work referencing lore docs for consistency
5. After writing, update lore docs with any new canon established
