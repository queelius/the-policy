# The Kindness Audit -- Local Lore

Story-specific worldbuilding, character notes, and editorial decisions
that apply to this short story only. For shared universe lore, see `lore/`
at the project root.

## Relationship to Shared Lore

- **Shared lore (`lore/`)** is canonical and authoritative for all works.
- **Local lore (this directory)** holds story-specific material:
  new characters, locations, timeline extensions, and editorial decisions
  that may or may not be promoted to shared lore.
- When local and shared lore conflict, shared lore wins unless
  the conflict is flagged and resolved.
